# Superstore_Sales_Analysis
Project Overview
This project is a comprehensive data analysis and visualization of sales performance.
The dashboard provides actionable insights into sales trends, category performance, and regional distributions using advanced Excel features.

🚀 Features & Skills Used
Data Cleaning: Processed raw sales data using Excel functions and SQL for accuracy.

Pivot Tables & Charts: Transformed complex datasets into digestible visual summaries.

Interactive Design: Custom-themed Slicers (Category & Year) that highlight selections while neutralizing others for better focus.

Time-Series Analysis: Monthly sales tracking updated from numeric (1-12) to month names (Jan-Dec) for better readability.

Professional Aesthetics: Clean white background with a consistent purple color palette for a modern UI/UX feel.

💡 Key Business Insights
Based on the analysis of the dashboard, here are the primary takeaways:

Monthly Trends: Sales show significant fluctuations throughout the year, with key peaks identified in the latter half of the year.

Top Performers: The Technology category consistently leads in terms of profit and revenue.

Customer Distribution: The "Customer Count" chart reveals steady growth over the 2011-2014 period.

Regional Sales: Specific states like England and New York emerge as high-revenue zones in the "Sales By State" analysis.

📂 Project Structure
Dashboard/: The main interactive sheet.

Cleaned_Data/: The processed dataset after removing errors and formatting.

Pivot_Calculations/: Background sheets containing the logic for the charts.

🛠️ How to Use
Download the .xlsx file from this repository.

Open it in Microsoft Excel.

Use the Category and Year slicers at the top to filter the entire dashboard instantly.
