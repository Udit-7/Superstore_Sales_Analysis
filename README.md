# 📊 Superstore Sales Analysis Dashboard

## 📝 Project Overview
This project is a comprehensive data analysis and visualization of sales performance.
![Superstore Sales Dashboard](Superstore_Sales.png)
## 🚀 Features & Skills Used
* **Data Cleaning:** Processed raw sales data using Excel functions for accuracy.
* **Pivot Tables & Charts:** Transformed complex datasets into digestible visual summaries.
* **Interactive Design:** Custom-themed Slicers (Category & Year) that highlight selections while neutralizing others.
* **Time-Series Analysis:** Monthly sales tracking updated from numeric (1-12) to month names (Jan-Dec).

## 💡 Key Business Insights
* **Monthly Trends:** Sales show significant fluctuations with key peaks identified in the latter half of the year.
* **Top Performers:** The **Technology** category consistently leads in terms of profit and revenue.
* **Customer Distribution:** The "Customer Count" chart reveals steady growth over the 2011-2014 period.
* **Regional Sales:** Specific states like England and New York emerge as high-revenue zones.

## 📂 Project Structure
* **Dashboard/:** The main interactive sheet.
* **Cleaned_Data/:** The processed dataset after removing errors.
* **Pivot_Calculations/:** Background sheets containing the logic for the charts.

## 🛠️ How to Use
1. Download the `.xlsx` file from this repository.
2. Open it in Microsoft Excel.
3. Use the Category and Year slicers at the top to filter the dashboard.
